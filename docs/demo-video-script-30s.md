## Timeline

| Time   | Beat            | Visual direction                                                                                               | Voiceover                                                                                              | On-screen text                         |
| ------ | --------------- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | -------------------------------------- |
| 0-4s   | Pain point      | Messy local agent folders, logs, cache files, and token fragments stack up around the app logo.                | AI coding agents move fast. Their local sessions, logs, caches, and token history pile up even faster. | Your AI workspace gets noisy fast.     |
| 4-9s   | Scan            | The app scans Codex, Claude Code, Cursor, Gemini, and OpenCode, then groups sessions into one clean dashboard. | Clean My Agent scans your local agent data across Codex, Claude Code, Cursor, Gemini, and OpenCode.    | Scan local agent sessions.             |
| 9-14s  | Cleanup         | Cleanup candidates appear with reclaimable space; files move toward app-managed Trash.                         | It finds stale logs, duplicate backups, and safe cleanup opportunities before anything is moved.       | Review cleanup candidates first.       |
| 14-19s | Restore         | A session moves back from Trash into the active session list.                                                  | Need something back? Restore from Clean My Agent Trash in one click.                                   | Restore from app Trash.                |
| 19-25s | Usage dashboard | Storage, sessions, and token usage charts animate into the dashboard.                                          | The usage dashboard shows where storage and token activity are going, by agent and by project.         | Understand usage by agent and project. |
| 25-30s | Privacy         | The dashboard closes into a shield, with credential-like files crossed out and local disk highlighted.         | It stays local-first, ignores credential-like files, and keeps you in control of cleanup.              | Local-first. Private by default.       |

## Notes

- Total duration: 30 seconds at 30 fps.
- The Remotion version uses animated product-style mock UI, so it can render without recording the desktop app.
- The closing privacy beat reinforces the safety model: read first, suggest cleanup first, move to app Trash, and avoid credential-like files.
